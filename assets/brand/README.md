# Brand reference

`hero-reference.png` is the aerial image the owner supplied as the brand
reference for the hero — the pool at golden hour with the mosaic mural and the
house behind it. It is **not** part of `assets/raw/` and is not in
`assets/manifest.json`, so the gallery never shows it: it is the source the hero
images were generated from, kept so they can be regenerated.

The heroes themselves are `assets/brand/hero-wide.jpg` (landscape) and
`assets/brand/hero-tall.jpg` (portrait, a separately generated 9:16 frame — not
a crop, because a 16:9 frame cover-cropped into a 390x844 phone shows about a
quarter of its width).
